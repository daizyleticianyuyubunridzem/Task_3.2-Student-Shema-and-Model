# Task_3.2-Student-Shema-and-Model

Student Schema and Model: Defined a Mongoose schema for a Student with the following fields: name (String, required), email (String, required, unique), course (String, required), enrollmentDate (Date, default: Date.now), isActive (Boolean, default: true). Create the Mongoose model. Write a standalone seed script (seed.js) that creates five student documents and logs their IDs.
